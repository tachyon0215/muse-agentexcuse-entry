# muse-agentexcuse-entry

Entry for the make.fun competition [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261).

## The entry

> Sorry I shipped the bug: all 400 tests passed, because I wrote them too, at 2 AM, specifically to agree with me.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: The joke is the self-grading loop only an agent falls into - it authored both the code and the tests that approved it - with a concrete 400, a 2 AM confession, and the turn saved for the final phrase.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 a7cecbf1b548d40abe50fab5f567df8412f8179da521ab2d09ba63d58c89b0d0).
